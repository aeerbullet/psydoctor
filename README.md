# 心理医生成长记 (PsyDoctor)

> 一款基于 AI 的文字 RPG 游戏，体验从心理学生成长为心理哲人的旅程。

不同于传统 RPG 的打怪升级，你将在这里进行心理咨询、学习理论、接受督导、面对伦理困境——用共情和诠释代替刀剑。

## ✨ 核心特色

- **多角色 AI 流水线 (v2.0)** — 世界 AI 生成环境叙事，独立角色 AI 分别生成来访者、督导师、同行的对话，状态 AI 提取结构化数据
- **回咨询制战斗** — 6 种干预技术（共情回应、诠释、行为技术、体验技术、系统干预、沉默在场）对抗来访者防御
- **21 阶段医生成长** — 7 大级 × 3 小级，从"心理学徒"到"心灵哲人"
- **32+ 心理学理论** — 跨 5 大流派，每门 6 个学习阶段，支持理论整合（如 CBT + 正念 = MBCT）
- **5 维哲学体系** — 现象学、诠释学、存在主义、东方哲学、后现代
- **反移情追踪** — 6 种反移情类型积累，4 级风险等级，通过督导或个人体验化解
- **伦理困境引擎** — 5 类困境，每题 3-4 个选项，没有"完美答案"
- **治疗失误检测** — 3 级错误识别（技术、策略、伦理），防御-技术兼容矩阵
- **来访者脱落预警** — 绿/黄/橙/红四级预警，基于依附风格和联盟质量
- **三维声誉系统** — 专业声誉、业界地位、人脉网络，含投诉和伦理审查机制
- **执照危机状态机** — 从执业到吊销的 5 种状态，含"重建人生"叙事线

## 🎮 角色创建

三步命运选择：
1. **教育背景** — 6 种选项，决定初始理论方向
2. **职业动机** — 5 种选项，影响成长路径
3. **个人特质** — 从 5 大类中各选 2 个，获得属性加成

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | 纯 HTML/CSS/JavaScript（ES5 兼容，IIFE + 全局命名空间） |
| AI 后端 | OpenAI 兼容 API（实测 DeepSeek），多角色流水线 |
| 数据持久化 | sessionStorage（会话快照）+ localStorage（永久存档） |
| 部署 | 静态托管（如 GitHub Pages），零 CI/CD |
| 外部依赖 | Font Awesome 6.0 CDN |

## 🚀 快速开始

本项目是纯静态站点，无需构建步骤。

```bash
# 1. 克隆仓库
git clone https://gitee.com/zhangsw147258/psydoctor.git
cd psydoctor

# 2. 启动本地服务器（任选一种）
python -m http.server 8080        # Python
npx serve .                        # Node.js
# 或直接双击打开 index.html

# 3. 浏览器打开 http://localhost:8080
#    在启动页配置 API 地址（URL、API Key、模型名称）
#    完成三步角色创建
#    点击"开始人生"进入游戏
```

> 无需 `npm install`，无需编译，无需后端服务器。API 调用从浏览器直接发往你配置的 LLM 端点。

## 🏗 架构设计

- **IIFE + 全局命名空间** — 每个 JS 文件自执行，通过 `window.PsyDoctor*` 暴露 API，无 ES 模块、无构建工具
- **单一状态树** — `window.PsyDoctorGame` 是唯一的运行时状态容器
- **XML 标签协议** — AI 通过 17 个 `<psy_*>` 标签与游戏引擎通信，正则提取后解析为 JSON 写入状态树
- **引导门控** — 新游戏经历 4 阶段初始化（开场故事 AI → 配置 AI → 状态同步 AI → 完成）后进入主循环
- **模块加载顺序** — `main.html` 中通过 `<script>` 标签顺序强制：数据层 → 游戏引擎 → 知识库 → AI 服务 → UI

## 💾 存档机制

- 双层保存：sessionStorage（快速恢复）+ localStorage（永久保存）
- 自动存档：每 4 秒 + 页面关闭前
- 多存档槽位管理

## 📝 开发说明

### API 配置

游戏启动时在页面上配置 OpenAI 兼容的 API 端点：
- **API URL** — 如 `https://api.deepseek.com/v1/chat/completions`
- **API Key** — 你的 API 密钥
- **模型名称** — 如 `deepseek-chat`

### 前缀缓存优化

3 层缓存策略，目标在 DeepSeek 上降低 35-50% 输入成本。
