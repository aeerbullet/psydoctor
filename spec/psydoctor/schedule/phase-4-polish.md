## 4.4 性能优化

### 4.4.1 渲染性能

- [ ] 面板全量重绘优化：
  - [ ] 非活跃面板延迟渲染（requestIdleCallback 或 setTimeout）
  - [ ] 大列表（来访者/藏书）使用 DocumentFragment 批量插入
  - [ ] 减少不必要的 innerHTML 赋值（仅数据变化时才重绘）
- [ ] 聊天区渲染优化：
  - [ ] 大量历史消息时使用虚拟滚动（或限制可见消息数）
  - [ ] 流式渲染使用 requestAnimationFrame 节流
- [ ] CSS 优化：
  - [ ] 减少重排/重绘（避免在循环中读取 offsetHeight）
  - [ ] 使用 `will-change` 提示浏览器优化
  - [ ] 动画使用 `transform` 和 `opacity`（GPU 加速）

### 4.4.2 存储性能

- [ ] localStorage 写入优化：
  - [ ] 存档 JSON 序列化前移除冗余数据（清理过期的 careerHistory 条目）
  - [ ] 存档文件压缩（可选：使用 LZString 压缩大存档）
  - [ ] 存档大小监控（> 500KB 时提醒用户清理旧存档）
- [ ] sessionStorage 恢复优化：
  - [ ] 测量 `restoreBootstrap()` 耗时 → 目标 < 100ms
  - [ ] 惰性恢复（优先恢复聊天区内容，延迟恢复来访者详情）

### 4.4.3 AI 调用优化

- [ ] 减少不必要的 AI 调用：
  - [ ] 状态 AI 响应为空或仅含纯叙事（无任何标签）→ 不重复调用
  - [ ] 用户输入过短（< 3 字符）→ 提示输入更长内容
- [ ] Token 消耗优化：
  - [ ] 历史对话轮次截断优化（按 token 数而非轮次数截断，目标 ≤ 4000 tokens for context）
  - [ ] 知识基底条目注入量按模型 context window 动态调整

### 4.4.4 验证

- [ ] Lighthouse 性能评分 > 80
- [ ] 首屏加载时间 < 3s（无缓存）
- [ ] 存档大小 < 200KB（中等游戏进度）
- [ ] `restoreBootstrap()` < 100ms
- [ ] 单次 AI 回合总耗时 < 15s（叙事 AI 流式 + 状态 AI）

## 4.5 边缘情况处理

### 4.5.1 状态边界

- [ ] 数值边界测试与钳制：
  - [ ] clinicalHours = 999999 → 确认无溢出
  - [ ] symptomLevel = 0 或 100 → 确认钳制正确
  - [ ] therapeuticAlliance = -10 → 确认钳制到 0
  - [ ] countertransference 任一类型 = 120 → 确认钳制到 100
  - [ ] philosophyDepth 值 = 15 → 确认钳制到 10
- [ ] 空状态处理：
  - [ ] currentClients = [] → 确认右栏显示"暂无来访者"
  - [ ] bookShelf = [] → 确认藏书网格显示"书架空空"
  - [ ] nearbyPeople = [] → 确认右栏显示"周围空无一人"
  - [ ] chatHistory = [] → 确认门闩触发条件正确

### 4.5.2 存档兼容性

- [ ] 存档版本兼容：
  - [ ] 定义存档 schema version（`G.schemaVersion = 1`）
  - [ ] `ensureGameRuntimeDefaults(G)` 检查 schemaVersion → 补全新字段
  - [ ] 未来新增字段 → 旧存档加载时自动补全默认值
- [ ] 存档损坏处理：
  - [ ] JSON.parse 失败 → 显示"存档损坏"错误 + 不覆盖旧存档
  - [ ] 必需字段缺失（fateChoice/doctorLevel/chatHistory）→ 拒绝加载
  - [ ] 部分字段类型错误 → 尝试修复（如字符串数字转为数字）

### 4.5.3 并发与竞态

- [ ] AI 调用竞态：
  - [ ] 用户快速连续点击发送 → `PSY_AI_GENERATING` 锁阻止重复调用
  - [ ] 上一轮 AI 未完成时用户点击「停止生成」→ AbortController 取消 + 清理
  - [ ] 多个 AI 调用同时返回（不应发生但防御）→ 仅处理最新回合
- [ ] 自动保存竞态：
  - [ ] autoSave 在 AI 生成中 → 跳过本轮保存
  - [ ] beforeunload 与 autoSave 同时触发 → 去重（仅执行一次）

### 4.5.4 网络与存储降级

- [ ] localStorage 不可用：
  - [ ] 检测 `window.localStorage` 是否可用（隐私模式可能禁用）
  - [ ] 不可用时仅使用 sessionStorage + 内存保存
  - [ ] 显示警告"浏览器不支持本地存储，存档无法持久化"
- [ ] sessionStorage 不可用：
  - [ ] 回退到内存中的 PsyDoctorGame 对象
  - [ ] 每次保存时尝试写入（若恢复则重新写入）
- [ ] 网络中断：
  - [ ] AI 调用失败 → 显示错误 + 允许重试
  - [ ] 保留用户输入（不清除输入框内容）

### 4.5.5 验证

- [ ] 模拟 localStorage 不可用 → 确认游戏仍可运行（仅当前会话）
- [ ] 模拟网络中断 → 确认错误提示正确 + 重试机制正常
- [ ] 快速连续点击发送 5 次 → 确认仅 1 次调用发生
- [ ] 加载故意损坏的存档 → 确认拒绝加载 + 不崩溃
- [ ] 加载 schemaVersion=0 的旧存档 → 确认自动补全新字段
